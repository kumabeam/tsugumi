# Tsugumi

会議を録音して文字起こしする、macOS のメニューバーアプリ。音声も文字起こしも Mac の外に出ない。

- Mac から出る音（相手）とマイク（自分）を同時に録る。仮想オーディオデバイスは要らない
- 録音は数秒おきに保存される。保存操作はなく、アプリが落ちてもそこまでの音声が残る
- 止めると自動で文字起こし。携帯で録った音声や画面収録のファイルも同じ流れで扱える

名前はツグミから。「口をつぐむ」が語源とされる、黙って聴いている鳥。

## 入れ方

macOS 15 以上の Apple Silicon Mac。

1. [Releases](https://github.com/kumabeam/tsugumi/releases) の zip を展開し、`Tsugumi.app` を「アプリケーション」に入れて開く
2. 「開発元を確認できない」と出たら、システム設定 > プライバシーとセキュリティ の「このまま開く」（初回だけ）
3. 文字起こしモデル（約3GB）のダウンロードが始まる。終わるまで待つ。録音はその間もできる
4. 最初の録音で「画面収録とシステムオーディオ録音」と「マイク」の許可を求められる。両方オンにして起動し直す

画面収録の許可は Mac から出る音を受け取るためのもので、画面は記録しない。

## 使い方

| したいこと | 方法 |
|---|---|
| 録音の開始／停止 | メニューバーのアイコン、ウィンドウ左下の赤いボタン、または ⌃⌥⌘R |
| ファイルを文字起こし | ウィンドウかメニューバーのアイコンにファイルをドロップ、または左下のファイルボタン |
| 結果を見る | 終了の通知をクリック、またはメニュー → 録音一覧を開く |
| 文字起こしを途中でやめる | メニューの「文字起こしを中止」、または一覧の右側の「中止」。音声は残り、後で「やり直す」ができる |
| 録音を消す | 右上のゴミ箱、一覧の右クリック、または ⌘⌫。ゴミ箱に入るので Finder から戻せる |

録音一覧では、行をクリックするとそこから再生する。スペースキーで再生／一時停止。⌘F で文字起こしの中を検索、タイトルは右上のタイトルをクリック、または左の一覧でダブルクリックして変更。
マイクは左下のマイクのアイコンから選ぶ。会議の検知、保存先、アップデートの確認は設定（⌘,）にある。音の出力先はどこでもよい。

## 出力

`~/Documents/Tsugumi/` に会議ごとのフォルダができる。

```
2026-11-09_1430/
├── transcript.md   文字起こし（時刻と「相手／自分」付き）
├── audio.m4a       録音（聞き返し用。1時間で約35MB）
└── session.json    状態の記録
```

「相手／自分」は Mac から出た音とマイクのどちらが大きいかで決めている。Mac のマイクだけで録った対面の打ち合わせや、取り込んだファイルには付かない。
